# 非功能测试指南

## 1. 目标与边界

本套件验证性能、容量、并发正确性、缓存与数据库故障行为、安全基线、移动端兼容性和 WCAG 2.1 A/AA 可访问性。

- 只使用 MySQL `news_app_test` 和 Redis DB 15。
- 使用单 Worker Uvicorn，本机结果只代表可复现的相对基线，不代表生产容量。
- 不连接正式数据库，不停止共享服务；故障场景改用不可达端口。
- 功能回归与现有 42 个测试独立，非功能门禁不会放宽其断言。

## 2. 环境

```powershell
.\.venv\Scripts\python.exe -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple -r requirements-nonfunctional.txt
cd toutiao_frontend
npm install
npx playwright install chromium
```

需要本机 MySQL 8 与 Redis 7。后端凭据放在 `.env.test.local`；前端生产构建显式使用 `/api` 相对路径，禁止把密钥写入 `VITE_*`。

## 3. 一键运行

```powershell
.\nonfunctional\run.ps1
```

快速工具验证：

```powershell
.\nonfunctional\run.ps1 --quick
```

标准流程顺序：

1. 验证隔离目标并重建测试库，在单事件循环中灌入固定数据。
2. 执行现有功能回归、前端生产构建。
3. 执行 14 个非功能 pytest 用例。
4. 执行 Python/前端依赖审计、Bandit 与密钥扫描。
5. 执行三次 20 VU、60 秒压测与冷缓存探针。
6. 启动 API 与 SPA/反向代理，执行 Chromium 移动端旅程与 axe。
7. 生成报告并清理测试数据。

所有阶段都会执行；只要任一项失败，统一入口返回非零退出码。

## 4. 固定数据

| 数据 | 数量 |
| --- | --- |
| 分类 | 8 |
| 新闻 | 10,000 |
| 关联新闻 | 30,000 |
| 用户 | 50 |
| 收藏 | 20,000 |
| 历史 | 50,000 |
| 热用户历史 | 10,000 |

数据使用固定 ID、时间、用户名和种子内容。热用户为 `user_id=1`；压测用户令牌固定，仅用于隔离测试库。

## 5. 分层命令

```powershell
# 后端非功能测试（自动准备与清理数据）
.\.venv\Scripts\python.exe -m pytest nonfunctional -m nonfunctional -v

# 安全扫描
.\.venv\Scripts\python.exe -m nonfunctional.security.run_scans

# 性能：20 VU / 60 秒 / 三次
.\.venv\Scripts\python.exe -m nonfunctional.performance.run

# 性能工具快速验证：5 VU / 10 秒 / 三次
.\.venv\Scripts\python.exe -m nonfunctional.performance.run --quick

# 前端构建、移动端旅程、axe
.\.venv\Scripts\python.exe -m nonfunctional.frontend.run
```

单独运行性能或前端检查时，先设置：

```powershell
$env:MYSQL_DATABASE = 'news_app_test'
$env:REDIS_DB = '15'
$env:PYTHONPATH = (Get-Location).Path
```

## 6. 严格门禁

| 质量属性 | 门槛 |
| --- | --- |
| 公共读 | P95 ≤ 300 ms |
| 认证读 | P95 ≤ 800 ms |
| 错误率 | < 1% |
| 非预期 5xx | 0 |
| 冷缓存 | 单请求 ≤ 500 ms |
| 并发详情 | 浏览量增量等于并发成功数 |
| 并发收藏 | 同一用户/新闻仅一条；唯一键竞态不得返回 5xx（当前复现 MissingGreenlet） |
| Redis 故障 | 5 秒内读取回源并返回 200；写操作不产生提交后错误 |
| MySQL 故障 | 5 秒内返回统一 503 |
| 依赖安全 | Python/npm 无 high/critical |
| SAST | Bandit 无 high |
| 密钥 | Git 跟踪文件无真实密钥，生产 JS 包无密钥 |
| 登录限流 | 连续失败登录后返回 429 + Retry-After |
| 移动端 | 375/390/440px 无横向滚动，无页面异常 |
| 可访问性 | 11 个路由 axe serious/critical 为 0 |

## 7. 结果与证据

- `nonfunctional/artifacts/suite-summary.json`：统一门禁结果。
- `nonfunctional/artifacts/backend-junit.xml`：pytest 证据。
- `nonfunctional/artifacts/security-scan.json`：安全扫描摘要。
- `nonfunctional/artifacts/performance-summary.json`：压测与冷缓存指标。
- `nonfunctional/artifacts/frontend-summary.json`：构建、包体积和浏览器质量。
- `nonfunctional/artifacts/load/`：Locust CSV 与输出。
- `toutiao_frontend/playwright-report/`：Playwright HTML 报告与截图。

原始证据默认被 Git 忽略。报告中只记录密钥所在文件、类型与修复建议，绝不记录密钥值。

## 8. 已知限制

不覆盖 TLS/HSTS 实网检查、DDoS、真实设备农场、Firefox/WebKit、Lighthouse、主动 ZAP、生产高可用与故障转移、CI/CD 接入。本机性能结论不得直接作为生产容量承诺。
